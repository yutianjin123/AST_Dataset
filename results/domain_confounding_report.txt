检验 1：控制负样本不变，正样本由【模拟】换成【真实】，性能落差是多少？
------------------------------------------------------------------------------

  场景 A  模拟正样本(3000) + 真实负样本(500) : AUC = 1.0000   Recall@0.5 = 0.9993
  场景 B  真实正样本(166) + 真实负样本(500) : AUC = 0.9804   Recall@0.5 = 0.6988

  >>> 落差 ΔAUC = 0.0196   ΔRecall = 0.3005
      这部分落差即为『模型依赖域捷径』所贡献的虚高性能。

  bootstrap 匹配样本量（每次抽 166 个模拟正样本，2000 次）：
    模拟正样本 AUC 分布 = 1.0000 ± 0.0000  [95% 区间 1.0000, 1.0000]
    真实正样本 AUC      = 0.9804
    >>> 单侧 p = 0.0000  （模拟正样本 AUC 低于真实正样本 AUC 的比例）
    >>> 结论：模拟正样本上的表现【显著优于】真实正样本，域捷径确实存在。

  顺带核对：常规报告的『模拟验证集』AUC = 1.0000
            真实测试集 AUC            = 0.9804
            虚高幅度                  = 0.0196
  >>> 论文中不应把模拟验证集的分类指标作为主要证据。

------------------------------------------------------------------------------
检验 2：模型对模拟正样本是否存在系统性过自信？
------------------------------------------------------------------------------

  模拟正样本 prob：均值 0.9989  中位数 1.0000  P(prob>0.99) = 0.9937
  真实正样本 prob：均值 0.6801  中位数 0.9515  P(prob>0.99) = 0.3253
  两者分布 KS 统计量 = 0.8912   p = 0.0000
  真实正样本中 prob<0.5 的漏检数 = 50 / 166
